# Assistara local website v5

Premium local prototype for Assistara, focused on client acquisition.

## Run locally on Windows
1. Make sure Node.js is installed.
2. Double-click `START-WEBSITE.bat`.
3. The site opens at `http://localhost:3000`.

No `npm install` is required. The server uses Node built-ins only.

## v5 direction
- Stronger premium startup-style hero.
- Assistara positioned as a delegation system, not a generic staffing agency.
- Clearer role-definition, matching, and ownership process.
- Stronger handling of the biggest objection: delegation creating more work.
- Client-facing copy uses “virtual assistant” rather than shorthand.
- No fake testimonials, logos, or customer counts.

The lead form is still a local demo and does not send data anywhere yet.
